## MTL-Housing-Price-Visualizer

A repository using Python (pandas, geopandas and plotly.express) to process and visualize Montreal average dwelling value progression over 1981 to 2021.

The data gathered was available through Concordia University's page on "Statistics & data", found at [Concordia Statistics & Data](https://library.concordia.ca/find/statistics.php).
Said data was provided by the **Canadian Census Analyzer** via *CHASS*, only available to Concordia members.
